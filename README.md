# H3 漫剧导演台（ComfyUI-H3-Director）

这是一个面向 ComfyUI 原生 MiniMax H3 工作流的中文长视频导演台。它把"多段生成、逐段验收"的漫剧制作流程整合进**一个节点**：可视化时间轴、每段独立提示词与参考图、每段配音音频、点段预览、单段重抽，段间通过尾帧文件自动接力，并按当前最新分段自动合并成片。

当前插件版本为 **2.40.2**。最低支持 ComfyUI **0.30.0**，推荐 **0.31.1 或更新版本**。导演台插件 ZIP 本身不包含模型，也没有复制 H3 的模型实现；另行交付的“离线环境包 ZIP”只用于二采节点与 Python 依赖的私人迁移，**不包含3D权重**。请先确认 ComfyUI 已带有 `MiniMax H3 Reference To Video` 和 `MiniMax H3 Image To Video` 原生节点。

## 特性

- 单节点整合多段漫剧制作：可视化时间轴、每段独立提示词 / 参考图 / 配音、点段预览、单段重抽
- 段间通过尾帧文件自动接力，按最新分段自动合并成片
- 创作 / 视频 / 文本三个工作页面，内置 AI 剧情、AI 分镜、AI 精修，支持 `@资产` 绑定参考图与人物音色
- 可选二采：学习型 3D latent 放大 + 低噪修复，内置显存分块与失败回退
- 独立视频超分页（AI 超分 / Lanczos），不接入或改变 H3 采样链
- 分段 MP4 原子检查点，失败可从断点继续；成片项目库支持保存 / 切换多个工程

## 环境要求

- ComfyUI ≥ 0.30.0（推荐 ≥ 0.31.1），Python 3.13
- ComfyUI 已自带 `MiniMax H3 Reference To Video` / `MiniMax H3 Image To Video` 原生节点
- 本插件不包含任何模型权重；H3 主模型、Ref2VA / FL2VA 与 3D 二采权重需另行准备（见文末"## 模型文件"）

## 快速开始

1. 按下方"## 安装"放置插件并安装依赖，**完全重启 ComfyUI**
2. 在节点搜索中输入 `H3 漫剧导演台·一体节点` 加入画布

## 基本接线

导演台左侧需要连接：

- `model`：唯一的大模型接口。把外部 `UNet加载器` 的输出连接到这里；需要切换 Ref2VA 或 FL2VA 使用场景时，只更换上游加载器选择的模型文件，插件会根据主模型类型自动选择对应 conditioning 和续接方式。
- `clip`：H3 文本编码器（Qwen3VL）。
- `vae`：H3 视频 VAE。
- `audio_vae`：H3 音频 VAE。
- `width` / `height`：输出分辨率（建议接 Resolution Selector）。
- `自动续接`：主 `model` 为 FL2VA 时使用 FL2VA 硬首帧；主 `model` 为 Ref2VA 时使用 Ref2VA 软参考，不需要第二个模型接口或手动选择。
- 原来的「续接方式」仍由插件自动决定。旧工作流中的隐藏「每段后卸载模型」只保留输入槽位兼容，加载后会强制关闭且后端忽略；节点始终只返回轻量预览，完整成片由磁盘 MP4 自动合并。

导演台右侧输出：

- `images`：只返回最后一个已完成段的尾帧，供 ComfyUI 预览与下游轻量检查。
- `audio`：返回静音占位；各段完整音频保存在 MP4，并进入自动合并成片。
- `fps`、`frame_count`：帧率与总帧数。
- `report`：运行报告文本。

### 从 2.13.x 工作流升级

- 旧工作流中的节点名和分段 JSON 保持兼容，打开后会自动生成并保存项目 ID。
- 旧工作流残留的第二模型输入和 `ref_image_N` 外部图片输入会在界面恢复时自动移除；把当前要使用的 Ref2VA 或 FL2VA 模型接到唯一的 `model` 输入即可。
- 参考图只在导演台资产库和“当前段实际参考”中管理，不再从节点左侧连接图片输入。
- 用户的 4.0 类加速工作流若使用 `TE-Speed-MiniMaxH3` 和 `ComfyUI-MiniMaxH3-TeaCache`，目标电脑也必须安装这两个外部自定义节点；它们不是本插件自带依赖。

## 分段与时间轴

1. 时间轴上每段是一个格子，标注 `段N · 起止秒数`；三个页面都可拖动格子右缘或点击时长标签，以 1 秒步进在 `2–15` 秒内调整。
2. 点选格子后，下方编辑区显示该段的提示词、参考图、音频与预览。
3. 直接在 ComfyUI 里运行节点：全部段按顺序生成，配置未变的段自动跳过；只勾一段的「启用」即只重跑该段。
4. 每段生成后立即写入 `output/video/h3director/<project_id>/漫剧_segN_00001_.mp4`，并在同一项目目录保存尾帧 `tail_segN_00001_.png` 供下一段接力——中途重启 ComfyUI 也不丢进度。

## 参考图与 @图N 语法

- 段 1 至少上传 1 张参考图；后续段可继续沿用（勾选续接尾帧即可），也可每段换图。
- 参考图编号规则：`Picture 1` 起按顺序编号——续接尾帧排最前，然后是本段上传图；节点内蓝条会实时显示当前编号对照。
- 提示词中写 `@图1` / `@图2`（兼容 `@image1`、`@img1`、`【图1】`），运行时自动转为 `<Picture 1>` / `<Picture 2>`。
- 更稳的方式：光标放在提示词里，直接点缩略图，自动插入正确编号。
- 换场景/换人物：取消"续接上段尾帧"，上传新图，改写提示词即可（编号前移，建议点缩略图重插）。

## 全局提示词（v2.13+）

节点顶部有一个**全局提示词**输入框（创作 / 视频 / 文本三个界面通用，隐藏在节点参数里）。它解决的问题是：很多提示词要素（全片美术风格、世界观设定、固定角色外观描述）每段都要写一遍。

- 填写后，运行节点时全局提示词会**自动拼到每一段提示词的最前面**（段提示词整体作为后半部分），再走 `@图N` 转换与 `<Picture N>` 注入——单段提示词里不用再重复这些常量。
- 留空则不拼接，完全退回"每段独立提示词"的行为。
- 典型用法：把 `Pixar-inspired 3D cartoon, soft lighting, 24fps` 这类全片统一风格写进全局框，每段只写当段动作/台词。
- **文本界面自动提取（v2.13.1+）**：全局框下方有「解析时自动提取共享提示词到全局框」勾选框（默认勾选）。勾选后，只有用户明确点击替换全部、导入到当前段或追加到末尾时，插件才会扫描导入内容、自动抽出安全的跨段共享身份、风格和限制并填入全局框；**单独点击「📂 载入文本」只更新脚本框，不解析、不修改全局框或现有段**。用户手填的全局内容不会被覆盖。

## 视频界面（参考视频驱动，v2.0+）

点编辑区的「⇄ 切到视频界面」：**上方放参考视频，下方放照片**——H3 原生支持参考视频（最多 3 路，2~15 秒）：

- **白模→成片**：上方放白模/灰模渲染视频（动作+运镜），下方放人物/场景照片，生成的视频沿用白模的动作和运镜、外观全部来自照片和提示词。
- **照片人物替换视频人物**：上方放原视频，下方放新人物照片，提示词写明替换关系。
- 点视频块自动插入 `<Video N>` 标签；后端自动追加官方 `reference` 结构化声明（动作/运镜/节奏跟视频，外观跟照片），不用手写。
- 参考视频默认选择「不发送音轨（推荐）」：只读取动作、构图、运镜和可见节奏，避免原视频杂音、伪语言或对白污染新视频。只有确实需要复刻原节奏/原台词，且原音轨干净时，才在当前段把「参考视频音轨」切换为「同时参考音轨」；白模无音轨也能正常使用。

> 提示：参考视频最长边预缩到 1280 控内存；段时长建议与参考视频时长相近。

## 文本界面（纯提示词生成 + 分镜脚本一键导入，v2.11+）

顶栏第三个页签「文本界面」：默认**不需要任何参考视频、参考图、配音、音色**——画面、人物、动作、运镜、台词、音效全部由 H3 按提示词原生生成。纯文本、无参考素材时可把 FL2VA 接到唯一的 `model` 输入执行 T2VA/FL2VA conditioning。与创作/视频界面数据完全独立，产出文件名也是独立的（`漫剧t_segN` / `tailt_segN`），三页互不覆盖。

核心用法是**分镜脚本解析导入**：把带时间标记的分镜文本粘进顶部脚本框，检查内容后选择「解析并替换全部段」「导入到当前段」或「追加到末尾」，插件再自动拆段、按标记设好每段时长、把对应正文写进每段提示词。「📂 载入文本」只选择本地 `.txt` 并填入脚本框，不会自动改变当前时间线。支持的标记写法（每段一个标记行）：

| 写法 | 示例 | 时长来源 |
|---|---|---|
| 段标记带时长 | `段1（6.6秒）：黄昏屋顶，少年转身……` | 括号里的秒数 |
| 段标记无时长 | `段1` + 正文里写 `[0s-3s] …` 时间轴 | 正文时间轴的最大结束秒 |
| 区间标记 | `[0s-6.6s] 开场……` / `0:00-0:06 …` / `0至6秒：…` | 区间差值 |
| 时长直写 | `6.6秒 \| 独白一场……` | 竖线前的秒数 |
| 官方 Shot 格式（v2.13.5+） | `integrated_multimodal_description: [Shot 1] … [Shot 2] At 00:00:03.000, …` 整段直贴 | `At HH:MM:SS.mmm` 绝对时间戳差值（末镜优先使用导入清单或明确范围终点） |

- 官方 Shot 格式（v2.13.8 起改为「按 15s 合并段」）：H3 单次能原生生成 ≤15s，且官方格式内部就用 `[Shot N] At mm:ss` 排子镜头时间轴——所以**总时长 ≤15s 的片子不再按 Shot 拆成多段，而是合并成「一段 = 一次生成」**，段提示词保留 `[Shot N] At` 结构让 H3 自己卡内部节奏；风格句 + `overall_soundscape` / `non_diegetic_music` 也一并并入这一段，成为完整自包含的官方提示词（不依赖全局框）。**总时长 >15s** 才按贪心把连续 Shot 装进 ≤15s 的生成桶（桶内 Shot 重新相对桶起点从 0s 计时），此时风格句与音效/配乐字段进全局提示词框、由各生成桶共享。
- 混用时以「段N」类标记为准切分（正文里的 `[0s-3s]` 时间轴标签不会误拆段）。
- 创作、视频、文本三个页面的生成段时长统一保存为 2–15 的整数秒；后端执行时自动换算为最接近的 H3 合法帧数。超过 15 秒的段会被截到 15 秒。
- **整篇没有任何标记的长文案（v2.13.9+）：按朗读时长智能分段**——直接粘贴整篇小说/旁白稿（不写任何标记），解析时自动按标准语速（4.5 字/秒）估算每句时长，切成**每段 8~15 秒**；断点优先级 = 段落换行 > 句末标点（。！？… .!?）> 从句标点（，、：），**绝不在句中硬断**（仅无标点超长句按字数兜底切），每段都是完整的镜头/情节描述，模型好理解。3 分钟文案（约 800 字）会自动分成十几段。
- 段间默认续接上一段尾帧（跨段动作连续），可在段行取消；段行还有独立的时长/种子。
- **种子随机范围选择**（v2.13.12+）：段行种子输入框左侧新增下拉，控制 🎲 按钮行为——**当段随机**（默认，只改当前段）、**全段各自随机**（所有段各换一个新种子，画面差异大）、**全段统一随机**（所有段共用同一个新种子，角色/风格更一致）。该选择随工作流保存，创作/视频/文本三界面通用。
- 脚本框内容随工作流保存；「📄 格式骨架」只提供可直接编辑的官方 Base 示例，「📂 载入文本」可选择本地 `.txt` 并载入脚本框。
- 「⚡ 解析导入」是整篇解析：用脚本解析结果替换当前页面的分段；已有内容时需再次点击红色确认按钮。文本页与创作页分别维护自己的脚本和分段，不互相覆盖。
- 手工编辑脚本后直接运行时，v2.24.24 会先自动执行同一套整篇解析；解析失败或时长明显膨胀时不会运行旧时间轴。
- 创作页的「资产库」与「当前段实际参考」分开：文件名默认作为资产名，可设置资产类型。资产不会按提示词自动绑定；把图片拖入当前段后才成为该段参考。每张资产可勾选「全局参考」，勾选后进入所有创作分段，不勾选则只保留在资产库或手动拖入过的分段。两个区域均可独立拖动调整宽高。
- 文本页、创作页、视频页是独立工作区。资产库只属于创作页，不会出现在文本页或视频页。
- 时间轴段块的时长数字可点选：点段块左下的「10s」弹出整数秒选择器，当前值高亮，点选即改；右缘拖拽调时长仍然可用并按整数秒吸附。

## 参考音色槽（多角色，A1~A3）

参考图下方有**参考音色槽 A1~A3**。当前界面中的这些槽按 `reference` 关系使用：只学习声音音色和表达方式，台词内容仍由提示词指定；旧工作流中保存过的槽级配音模式字段仍由后端兼容读取。

- 点槽块自动在提示词插入 `<Audio N>`；也可手写 `@音1` / `@音2`（自动转 `<Audio N>`）。
- 提示词里把音频和人物绑定即可，如：`<Audio 1> 是 <Picture 1> 角色（S1）的音色参考`。
- H3 最多 3 路独立参考音频：本段音频的「参考驱动」占第 1 路时，音色槽编号自动从 A2 起（面板有提示）。
- 要让角色 1:1 复用一段配音并对口型，请使用本段音频的「参考音频驱动」，而不是参考音色槽。

## 环境音（重要认知）

参考音频（配音/音色槽）的条件会压制 H3 自生成环境音——提示词写"风声鸟鸣"也常常不出（实测参考音频贯穿采样全程，模型只顾模仿人声音色）。

**想要 H3 原生环境音/音效：该段不要挂任何参考音频**，纯提示词驱动（模型音频模式），
环境音写具体拟声（`wind chime rings, ding, ding`）最有效。实用策略：对话段挂音色槽保台词，空镜/转场段不挂、专门出环境音，交替排布。

## API 设置

顶部 **API 设置** 只使用你主动配置的 **OpenAI-compatible API**。当前前台用途是连接测试，以及创作页在文件名、资产名和别名仍无法确定时的资产匹配；本地确定性名称匹配不需要 API，也不会下载或加载本地提示词模型。

- 在顶部 API 设置中可选择 CodexCN、OpenAI、DeepSeek、OpenRouter、硅基流动或阿里云百炼，Base URL 会自动填写；其它中转站选择「自定义 / 中转站」。
- 模型选择提供各服务商常用模型快捷项；列表没有的新模型选择「自定义模型」，再手动填写模型 ID，不会被固定列表限制。
- 填写 `API Key` 后点「**保存设置**」。
- 点「**测试连接**」会保存当前设置并发送一次最短文字测试；只有主动测试或创作页确实需要不确定资产匹配时才联网。
- 自动资产匹配发送的是分段文字以及资产稳定 ID、名称和类型，不发送本地文件路径，也不把整个资产库无条件塞入每一段。
- API 离线、未配置或漏回某段时，该段保持本地匹配结果或空缺，不会用完整资产库兜底。明确写“无人、空镜、人物离场”的段不会被 API 加回角色。
- API Key 只保存在本机 `ComfyUI/user/ComfyUI-H3-Director/api_config.json`；前端接口只查询是否已配置，Key 不写入工作流、节点属性、localStorage 或日志。
- Base URL 通常填写到 `/v1`，插件会自动调用 `/chat/completions`；如果服务商给的是完整 `/chat/completions` 地址，也可以直接填写。

## 段级音频

每段音频来源二选一（v1.7.3 起；旧工作流里的"替换/混合"段会显示"旧版"选项兼容）：

| 模式 | 说明 | 口型 | 需要上传 |
|---|---|---|---|
| 模型音频（H3 生成） | 默认，H3 自己生成的声音和环境音 | 同步 | 否 |
| **参考音频驱动（v1.6+，配音推荐）** | 上传配音喂给 H3 当生成条件（`<Audio 1>`），模型听着它说台词 | **原生同步** | 是 |

> **想让角色说你的配音且口型对上，选「参考音频驱动」**。替换/混合只是把音轨贴到成片上，
> 嘴部动作仍按模型自己的节奏动，必然错位——这是原理决定的，不是 bug。
>
> 参考音频驱动有两个子模式（v1.6.1+，按 MiniMax 官方 R2V 提示词指南实现）：
>
> | 子模式 | 官方关系 | 效果 |
> |---|---|---|
> | 复刻音轨（默认） | `fully_copy` | 你的配音 1:1 用作成片音轨，画面口型对齐它（配音台词首选） |
> | 复刻音轨 + 保留 H3 环境音（v1.7+ 勾选） | `partially_copy` | 配音作对话轨 1:1 复用，H3 同时生成环境音/音效/配乐 |
> | 仅音色参考 | `reference` | 模型只学音色语气，台词按提示词重新生成（声音克隆） |
>
> 插件会按子模式自动向提示词追加官方结构化声明（`subject_definitions` / `retention_analysis` /
> `detailed_description` + `<Audio 1>` 标签）——没有这段声明模型会忽略参考音频（v1.6.0 实测踩坑）。
> 裁剪/挖洞/起始偏移在此模式同样生效（先处理音频再喂给模型），音量不适用。
> 建议配音时长与段时长接近（音长警示会提示差距）。

- 上传后显示**波形编辑器**：拖双柄裁剪（保留选中区 / 删除选中区中间挖掉），支持 `wav/mp3/m4a/ogg/flac/aac`。
- `起始偏移`：配音从段内第 X 秒开始播（自动对齐段时长，长截短静音）。
- 采样率/声道自动统一（TTS 常见的 22050Hz mono 也能直接与 32000Hz stereo 模型声混合）。
- 时间轴下方的 `AUDIO` 轨道显示每段音频状态，点"开/关"可让某段输出无声视频。
- **三种添加方式**（v1.5+）：`+音频` 按钮上传；**把音频文件直接拖到 AUDIO 轨道的段块上**；或从**音频库下拉**直接选用 input 目录里已有的音频（不用重复上传）。
- **音长警示**（v1.5+）：音频有效时长盖不住段长（尾部无声）或超出段长（被截断）时，AUDIO 段块和裁剪区会显示黄色 ⚠ 提示。
- **台词时长建议**（v1.5+）：提示词里用引号写台词（`"台词"`），编辑区顶部实时显示三档语速（慢/标准/快）的整数秒建议时长，点击即应用——写对话戏不再靠猜时长。

## 预览与逐段验收

- 点选段落，编辑区底部出现该段的视频播放器（带声音、可拖大、可新窗口放大）。
- 一键运行全部段后会自动合并；逐段过一遍时若某段不满意，直接点该时间线段卡里的「重抽」，只替换这一段，结束后自动用其他段的原片重新合并。
- 「合并成片」可随时手动重建；成功后会在导演台内直接播放。「查看成片」始终显示，当前界面已有合并 MP4 时可随时重新打开。创作、视频、文本三套产出和合并文件彼此独立。
- 面板顶栏常显版本号；若状态栏出现红色版本警告，说明前端/后端有一边是旧代码，按提示重启或强刷即可。

## 时长、帧数与帧率

- H3 固定按 **24 帧/秒** 生成，帧数自动对齐到 `17n+5`，最终时长与填写值可能有 ≤0.5 秒差异。
- 每段可单独设置**输出帧率 8~24**：调低为抽帧（时长不变，呈逐帧动画感）。各段帧率不同时合流输出会自动统一。

## 输出分辨率

建议配合 Resolution Selector 使用：默认 `16:9 / 0.4MP / 32`（约 832×480，与 H3 原工作流一致，16GB 显存实测每 10 秒段约 8~12 分钟）。追求画质可升 `0.9MP`（约 1280×704），耗时与显存相应增加。

## 输出文件位置

每个导演台节点首次创建时会生成持久化 `project_id`。全部产物按项目隔离在：

```
ComfyUI/output/video/h3director/<project_id>/
```

创作界面示例：

```
漫剧_seg1_00001_.mp4    第 1 段成片（每段独立；创作界面）
漫剧_seg2_00001_.mp4    第 2 段成片
tail_seg1_00001_.png    第 1 段尾帧（接力用，无需管理）
漫剧_segN_00001_.json   第 N 段配置缓存（哈希跳过用，无需管理）
```

视频界面产出独立命名（`漫剧v_segN` / `tailv_segN`），文本界面同样独立（`漫剧t_segN` / `tailt_segN`），三个界面的成片与缓存互不覆盖。

### 自动合并与内存

- 界面已移除高内存“汇总输出”下拉框。各段 MP4 始终保留完整画面和音频；节点 `IMAGE` 只返回最后一段尾帧，`AUDIO` 返回极短静音占位，`frame_count` 仍统计所有已完成段折算到 24fps 的总帧数。
- 点击“运行”后会在所有启用段完成时自动合并；点击时间线段卡里的“重抽”后会覆盖该段固定文件，并自动按全部启用段的最新文件重新合并，因此能得到 `1-2-新3-4`。顶部“合并成片”按钮仍作为手动补救。
- 这种方式不会把整片所有帧与音频重新读回 Python 张量，长项目和普通内存环境更稳定。
- 单段 MP4 写出同样采用逐帧 FFmpeg stdin 流：Python 不再额外保存一份整段 RGB `bytes` 副本，从而降低的是**系统内存**编码峰值；模型采样和 VAE 解码所需的**显存**不会因此减少。

## 素材上传限制

- 参考图：常见 `jpg/png/webp`，由 ComfyUI 内置图片上传接口接收，建议单张不超过 10MB。
- 自定义音频：`wav/mp3/m4a/ogg/flac/aac`，后端限制 **100MB/文件**；内容时长建议与单段接近。
- 参考视频/续接视频：`mp4/webm/mov/mkv/avi`（续接主要使用 mp4），后端限制 **2GB/文件**；实际可上传上限还会受浏览器、反向代理和 ComfyUI 服务配置影响。
- 上传素材保存在 ComfyUI 的 `input` 目录，工作流只保存文件名，不写入媒体二进制。

## 外部低显存与加速节点筛选

本插件没有把用户提供的 4 步/6 步大工作流整套复制进来，也没有新增强制 custom node。原因是导演台的目标是把稳定的素材分配、分段缓存、重抽和合并能力集中在一个节点中；把 Krea2、Z-Image、Yuan、MultiImageLoader、GGUF、ControlNet 和多套 LoRA 一起带入，会显著增加缺节点、缺模型、爆显存和版本冲突的概率。

v2.36.1 的验证顺序固定为：先复测同一 5 秒成功路径，再测试 15 秒；只有资源交接修复后的 15 秒仍然 OOM，才单独进入 KJNodes 低显存节点真实 A/B。KJNodes 没有被自动集成、复制或设为插件依赖，本轮也没有执行该 GPU A/B。

需要降低显存或加速时，可在上游工作流中自由连接第三方节点。导演台不会检查、阻止、警告或改写这些节点：

1. 优先使用官方/Comfy-Org 的 INT8 H3 模型，不要把完整高精度模型常驻显存。
2. 如已安装较新的 `ComfyUI-KJNodes`，可选 `MiniMaxChunkFeedForward`（例如 chunks=4、seq_threshold=4096）。它按 token 分块降低前馈峰值显存，但仍标记 experimental；导演台只诊断，不自动追加。
3. 仍缺显存时再单独尝试 `MiniMaxLowVRAMAttention`。它按 attention head 分组并尽早释放中间张量，源码声明不改变数学结果，但同样是 experimental。
4. `SolAttnPatch`、Memory-Efficient SageAttention 等注意力替换只作为可选 A/B；不要一次叠加多套。社区曾报告部分 GPU/版本使用 H3 Memory-Efficient SageAttention 时无报错却输出灰噪，因此导演台不会自动开启。
5. Turbo LoRA、剪枝模型和外部 TurboSampler 也可自由接入；具体步数、音频/video flow schedule、兼容性和输出质量由所连接的第三方节点与模型共同决定，导演台不做额外判断。

导演台只消费最终接入的 `MODEL`，不会替用户自动改线、安装节点或干预上游模型链。

## 常见问题

**改了代码/界面没变化**
前端改动：浏览器 `Ctrl+Shift+R` 强刷；后端改动：完全重启 ComfyUI 进程。面板顶栏有版本号，可对照确认。

**预览黑屏 0:00**
老版本生成的视频缺少 faststart 头，重跑该段即可（v1.3+ 生成的视频均自带）。

**换场景后画面发糊**
参考图驱动模型的正常表现：没有尾帧照画时，模型需要凭空构造新场景。建议新场景段落升到 0.9MP，并把场景图放在参考图第一位。

**提示词里出现 `<Picture N>` 英文标签**
这是 H3 识别参考图所需的官方控制标签，正文仍可全部用中文书写。

**导演台有声音破碎/杂音，官方原生工作流正常**
2.20 已统一修复音频写出和合并参数。若单段刚生成时仍有破碎声，可自行旁路上游第三方加速节点并与原生模型链对照；导演台不会扫描或干预已经进入 `MODEL` 对象的外部修改。

**运行时报 `Command '[...triton...tcc.exe', ...]' 失败（Windows + Python 3.13）**
报错来自 H3 模型推理链路里的 Triton 即时编译（triton-windows 用自带的 tcc 链接 CUDA / Python 库），与本插件代码无关，属于整合包环境问题，按顺序尝试：
1. 把整合包 Python 的 `libs\python313.lib`（通常在 `python_embeded\libs`，若无则从同版本官方 Python 拷贝）放到可被 tcc 找到的位置，或复制到 `python_embeded\libs` 目录下；
2. 确认已安装 CUDA Toolkit（报错命令行里引用了 `CUDA\v12.x`），并把 `CUDA\bin` 加入 PATH；
3. 在 H3 采样相关节点里把注意力实现从 Triton/SageAttention 切换为 SDPA（如节点提供该选项），绕开 Triton 编译；
4. 仍不行：把完整报错文本（不是截图）发给 H3 整合包/模型节点的作者——编译命令的最后几行才是真正的失败原因。

**面板变窄/比例不对（v1.4.1 已修复）**
低画布缩放下拖拽位移未换算导致的跳变，及个别前端版本下面板宽度脱离节点宽度的问题，已在 v1.4.1 修复：所有拖拽按画布缩放换算，并加了宽度看门狗自动校正。遇到旧版残留状态，把节点拉大一次即可恢复。

- `时长守恒门槛（v2.22）`：官方 Base/Ref2VA 从绝对 Shot 时间轴或导演台清单取得源时长，中文档案分镜汇总显式时长；导入时只允许 H3 合法帧档位造成的小幅吸附偏差。文本页与创作页的整批导入/当前段导入都会拒绝明显膨胀，生产前检查显示“脚本源时长 → 当前执行时长”，普通文本则明确标为估算。
- `官方字段交付门槛（v2.22）`：每个生成段都必须保留 Base 三字段或 Ref2VA 六字段及正确顺序；缺字段、字段顺序错误、Shot 时间不递增，或把 `director_import_manifest` 混入 H3 段提示词，都会阻止导入或生成。
- `官方 Base AI 格式`：段级 AI 现在输出 `integrated_multimodal_description / overall_soundscape / non_diegetic_music` 三字段；首镜无时间戳，后续镜头使用绝对时间，台词使用 `(S1)` 与 `<d>[Chinese]…</d>`，默认 `non_diegetic_music: N/A`，降低多段配乐和声音声明互相冲突的概率。
- `尾帧接力`：每段生成后自动把最后一帧存盘，下一段勾选"续接上段尾帧"即从此画面无缝继续；取消勾选即可换场景换人物。也可用"从视频续接"上传任意 mp4 抽尾帧当起点。
- `段级音频`：每段可选 `模型音频（H3 生成）` / `参考音频驱动（对口型）`；参考音色槽 A1~A3 给不同角色配指定嗓音；支持波形可视化裁剪、起始偏移、整段静音开关；AUDIO 轨道一眼看清每段用什么声音。
- `点段预览`：点选段落即可在节点内播放该段已生成的视频（带声音、可自由缩放），想重跑哪段一眼定位。
- `单段重抽 + 自动重合并`：只给当前段换种子并重新生成，其他段原样保留；例如重抽段 4 后会自动得到 `1-2-3-新4-5` 的最新合并成片。
- `启用段合并保护（v2.20.1）`：手动合并和全部生成后的自动合并只包含当前启用段；单段重抽时使用运行前的启用快照，并强制包含当前重抽段，避免临时停用其它段造成只合并一段或把已禁用的旧片误加回来。
- `音频稳定化`：模型原声、替换、混合、环境音和最终合并统一为 32000Hz 双声道，修正时间戳与直流偏置，保守限幅并对分段首尾做极短淡化，降低砂声、削波和连接爆音。
- `无对白防伪语言`：提示词未包含精确 `<d>...</d>` 台词时，后端会追加最高优先级禁语音契约，禁止对白、旁白、歌词、耳语、咕哝和伪语言；参考视频默认只发送画面，不发送原音轨。模型音频写出前还会清理 NaN/Inf 和异常超幅，避免无效波形变成爆音或方波砂声。
- `单段合并免转码`：项目只有一个启用段时，合并成片直接原子复制已验收段文件，不再重新编码画面和 AAC；多段项目仍使用 32kHz 双声道无损 PCM 中间音轨并只在最终成片编码一次 AAC。
- `全面板缩放`：面板顶部拖条放大整个节点；提示词、参考图、预览区各有独立拖条。
- `分段与合并同时保留`：每段仍保存独立 MP4，可直接拖进剪辑软件；全部生成或单段重抽结束后会自动按当前分段重新合并，顶栏也可随时手动合并。
- `项目隔离`：每个导演台节点保存独立 `project_id`，不同工作流/不同导演台的段视频、尾帧和缓存不会互相覆盖。
- `省内存汇总`：始终只向 ComfyUI 返回最后一段尾帧和静音占位，完整音画仍保存在每段 MP4 并自动合并；不再提供高内存完整张量汇总。
